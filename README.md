# FreePKG-Manager
FreeRoot Package Manager
esse é um sistema e gerenciador de pacotes que eu fiz para o FreeRoot Linux. funções: instalar packages com scripts shell; instalar binários em C compilados; resolver dependências automaticamente; verificar checksum ao baixar packages (md5); registrar o que está instalado; excluir pacotes (incluindo os arquivos); atualizar índice local; atualizar packages.

-- english: -- this is a package handler that i made for the FreeRoot Linux. functions: install packages with shell scripts; install compiled C binaries; automatically resolve dependencies; check checksum when downloading packages (md5) register which packages are installed; delete packages (including files); update local index; upgrade packages.
